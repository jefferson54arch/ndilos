
# 💜 NDIL OS

**Açık kaynaklı, Debian tabanlı Linux dağıtımı.**

NDIL OS, eski ve yeni bilgisayarlarda kullanılabilecek, sade ve özelleştirilebilir bir Linux deneyimi sunmayı hedefler.

## ✨ Özellikler

- 🐧 Debian tabanlı altyapı
- 🖥️ LXQt masaüstü ortamı
- 💜 Siyah ve mor neon tasarım
- 🌍 Türkçe dil desteği
- 📦 APT paket yöneticisi
- 🔴 Live ISO desteği
- 🧩 AppImage desteği hedefi
- 🪟 Wine desteği hedefi

## 🎯 Hedef

NDIL OS'nin amacı, mümkün olduğunca geniş bir x86 bilgisayar yelpazesinde çalışabilen hafif bir işletim sistemi oluşturmaktır.
